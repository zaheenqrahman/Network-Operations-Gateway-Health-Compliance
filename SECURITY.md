# Security Policy

## Supported versions

The project is currently in active development. Please use the latest version on the `main` branch for the most current fixes and security updates.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, contact the repository maintainer privately and provide:

- a clear description of the issue
- affected files, versions, or configuration
- reproduction steps, if available
- any suggested mitigation

We will review and respond as quickly as possible.
