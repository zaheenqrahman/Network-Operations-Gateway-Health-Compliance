# Contributing

Thanks for your interest in improving NetOps Gateway.

## Development workflow

1. Fork the repository and create a feature branch.
2. Keep changes scoped and focused.
3. Write or update tests when relevant.
4. Run local validation before submitting a PR.
5. Open a pull request with a clear summary and relevant screenshots or logs if needed.

## Code style

- Prefer clear, readable Python code.
- Use type hints where practical.
- Keep secrets and environment values out of source control.
- Document key configuration variables and deployment assumptions.

## Reporting issues

Use GitHub Issues to report bugs, feature requests, or deployment problems.
